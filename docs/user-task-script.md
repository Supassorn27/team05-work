## User Task Script

สวัสดีครับ/ค่ะ ขอบคุณที่สละเวลาเข้าร่วมการทดสอบโปรเจกต์ของทีมเรา
ปัจจุบันระบบยังอยู่ในขั้นตอนการพัฒนา โดยมีวัตถุประสงค์เพื่อศึกษาว่าผู้ใช้สามารถเข้าใจการแสดงผลข้อมูลและการทำงานของระบบได้หรือไม่
ระหว่างการทดสอบ หากพบจุดที่สับสนหรือมีข้อเสนอแนะเพิ่มเติม สามารถแสดงความคิดเห็นได้อย่างเต็มที่
การทดสอบครั้งนี้เป็นการประเมินต้นแบบของระบบ ไม่ใช่การประเมินความสามารถของผู้ใช้งาน
ขออนุญาตบันทึกความคิดเห็นและข้อมูลที่เกี่ยวข้องกับการทดสอบ เพื่อนำไปใช้ในการปรับปรุงและพัฒนาระบบต่อไป
