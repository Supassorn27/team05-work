# Pain Point ที่พบระหว่าง Test

สรุป pain point เบื้องต้นที่พบจากการ test

| Pain Point | พบจากผู้ใช้กี่คน | กระทบ Core Flow หรือไม่ | Evidence |
| --- | --- | --- | --- |
| ผู้ใช้ไม่แน่ใจว่าข้อมูลอุณหภูมิบน Dashboard เป็นข้อมูล Real-time ไหม | 1 คน | Yes | เพื่อนนักศึกษา ถามว่า "อุณหภูมิตอนนี้ 30°C ใช่ไหม" และใช้เวลาสักพักในการอ่านข้อมูล |
| ผู้ใช้ไม่ทราบเงื่อนไขการเปิดพัดลมอัตโนมัติ | 1 คน | Yes  | เจ้าของสัตว์เลี้ยง ถามว่า "พัดลมเปิดตอนไหน" และมองหาข้อมูลเพิ่มเติมบนหน้าจอ |
| หน้าจอไม่มีการแสดงสถานะการอัปเดตข้อมูลล่าสุด | 1 คน | No | เพื่อนนักศึกษา สงสัยความถูกต้องของข้อมูลที่แสดง ทำให้เกิดความไม่มั่นใจ |
