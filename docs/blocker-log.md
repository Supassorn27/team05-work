## Blocker

| Blocker | กระทบ component ใด | ใครรับผิดชอบ | ลองแก้แล้วอย่างไร | ต้องการให้ใครช่วย |
|---|---|---|---|---|
| Dashboard ยังไม่อัปเดตข้อมูล real-time | Frontend Dashboard | Frontend | ทดลอง subscribe topic ใหม่ | Backend ช่วยตรวจ payload format |
| Relay ทำงานหน่วงบางครั้ง | Hardware Control | Embedded / IoT | เปลี่ยน delay และทดสอบไฟเลี้ยงใหม่ | เพื่อนในทีมช่วยตรวจ wiring |
