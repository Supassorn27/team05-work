## Pattern & Insight

| Pattern ที่พบ | หลักฐาน | Insight ที่ทีมได้ |
| --- | --- | --- |
| ผู้ใช้คาดหวังข้อมูลอัปเดตแบบ Real-time | กังฟู กดรีเฟรชหน้าเพื่อดูข้อมูลใหม่ | Dashboard ควรอัปเดตอัตโนมัติเมื่อ Sensor ส่งข้อมูลใหม่ |
| ผู้ใช้ต้องการทราบสถานะพัดลมอย่างชัดเจน | กังฟู มองหาสถานะการทำงานของพัดลม | ควรใช้สีและไอคอน เช่น สีเขียว = OFF, สีแดง = ON |
| ผู้ใช้มองไม่เห็นความสัมพันธ์ระหว่างอุณหภูมิกับการเปิดพัดลม | อาโป สงสัยว่าทำไมพัดลมเปิดเอง | ควรแสดง Threshold เช่น “Fan ON เมื่ออุณหภูมิ ≥ 30°C” |

## Top Insights

- Insight 1: ผู้ใช้ต้องการข้อมูลที่อัปเดตเร็วเพื่อเพิ่มความมั่นใจในการใช้งาน
- Insight 2: ผู้ใช้มองว่าการแสดงผลช่วยตรวจสอบการทำงานของระบบได้
- Insight 3: การแสดงสถานะที่ชัดเจนช่วยให้เข้าใจระบบได้เร็วขึ้น
