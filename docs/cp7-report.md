## 8. Next Steps / Future Work

หลังจากพัฒนา Prototype v2 ทีมมีแผนที่จะพัฒนาระบบต่อในด้านต่าง ๆ ดังนี้

1. พัฒนาระบบการเชื่อมต่อข้อมูลแบบ Real-time
- ปรับปรุงการส่งข้อมูลจากอุปกรณ์ให้รวดเร็วและเสถียรมากขึ้น

2. เพิ่มระบบแจ้งเตือนผ่านแอปพลิเคชัน
- เพิ่มการแจ้งเตือนเมื่ออุณหภูมิสูงเกินค่าที่กำหนด เพื่อให้ผู้ใช้รับรู้สถานะได้ทันที

3. เพิ่มระบบจัดเก็บข้อมูลย้อนหลัง
- บันทึกข้อมูลอุณหภูมิและสถานะการทำงาน เพื่อให้สามารถนำข้อมูลไปวิเคราะห์ได้

4. ปรับปรุง Dashboard
- พัฒนาการแสดงผลข้อมูลให้เข้าใจง่ายและเหมาะกับการใช้งานมากขึ้น
