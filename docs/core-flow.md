## Core Flow
ผู้ใช้เปิดระบบตรวจวัดอุณหภูมิ → ระบบตรวจจับและประมวลผลอุณหภูมิภายในห้อง → ผู้ใช้ได้รับการควบคุมพัดลมอัตโนมัติเพื่อรักษาอุณหภูมิให้เหมาะสม

## อธืบายเพิ่มเติม
| คำถาม | คำตอบ |
|---|---|
| ผู้ใช้หลักของ flow นี้คือใคร? |	เจ้าของสัตว์เลี้ยงที่ไม่สามารถอยู่ดูแลสัตว์เลี้ยงได้ตลอดเวลา |
| input แรกของ flow คืออะไร?	| ค่าอุณหภูมิจากเซนเซอร์ |
| ระบบต้องประมวลผลอะไร? |	วิเคราะห์อุณหภูมิและสั่งเปิด-ปิดพัดลมอัตโนมัติ |
| output ที่ผู้ใช้จะเห็นคืออะไร? |	พัดลมทำงานอัตโนมัติเมื่อเซนเซอร์อ่านค่าได้ถึงตามอุณหภูมิที่กำหนดไว้ |
| ทำไม flow นี้สำคัญที่สุดต่อโปรเจกต์? | ช่วยดูแลความสบายและลดความเสี่ยงที่สัตว์เลี้ยงจะร้อนเกินไปเมื่ออยู่บ้านคนเดียว |

## Sprint Goal
ใน Sprint 3 ทีมเราจะทำให้ระบบสามารถเปิด-ปิดพัดลมอัตโนมัติตามอุณหภูมิที่ตรวจวัดได้จริง
