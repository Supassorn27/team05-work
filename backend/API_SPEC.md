# API Specification

## ภาพรวมระบบ

ระบบ Pet Care ใช้ Firebase Realtime Database ในการจัดเก็บข้อมูลที่ส่งมาจาก ESP32 และใช้สำหรับแสดงผลบนหน้าเว็บแบบ Real-time

---

## Temperature

Path:
`/temperature`

ประเภทข้อมูล:
`float`

รายละเอียด:
เก็บค่าอุณหภูมิที่อ่านได้จากเซ็นเซอร์ DHT11

ตัวอย่างข้อมูล:
`28`

---

## Humidity

Path:
`/humidity`

ประเภทข้อมูล:
`float`

รายละเอียด:
เก็บค่าความชื้นที่อ่านได้จากเซ็นเซอร์ DHT11

ตัวอย่างข้อมูล:
`65`

---

## Fan Status

Path:
`/fanStatus`

ประเภทข้อมูล:
`string`

รายละเอียด:
เก็บสถานะการทำงานของพัดลม

ตัวอย่างข้อมูล:
`ON`

ค่าที่เป็นไปได้:

* ON
* OFF
