# เอกสาร API

## GET /status

คำอธิบาย:
ใช้สำหรับดึงข้อมูลสถานะปัจจุบันของระบบ ได้แก่ อุณหภูมิและสถานะพัดลม

ตัวอย่างผลลัพธ์

```json
{
  "temperature": 27.5,
  "fanStatus": "OFF"
}
```

---

## GET /temperature

คำอธิบาย:
ใช้สำหรับดึงค่าอุณหภูมิปัจจุบันจากเซ็นเซอร์

ตัวอย่างผลลัพธ์

```json
{
  "temperature": 27.5
}
```

---

## GET /fan-status

คำอธิบาย:
ใช้สำหรับดึงสถานะการทำงานของพัดลม

ตัวอย่างผลลัพธ์

```json
{
  "fanStatus": "OFF"
}
```

---

## POST /login

คำอธิบาย:
ใช้สำหรับเข้าสู่ระบบ

ตัวอย่างผลลัพธ์

```json
{
  "success": true,
  "message": "เข้าสู่ระบบสำเร็จ"
}
```

---

ตัวอย่างผลลัพธ์

```json
{

  "message": "สมัครสมาชิกสำเร็จ"

```
